PROBLEM STATEMENT & INDUSTRIAL NEED
Why Traditional 2D AOI Cameras Fail on Modern PCBs
Limitations of Legacy 2D AOI Systems
  • Flat 2D Blind Spots: Top-down 2D cameras cannot see vertical pin lift ($0.05 ext{ mm}$ air gap), leading to catastrophic field failures.
  • Specular Mirror Glare: Shiny SAC300 melted solder creates blinding reflections that produce false alarms.
  • Zero Physical Metrology: Cannot measure true micrometer height, wetting angle, or liquid paste volume.
  • High False Call Rate (FCR): Operators waste hours manually re-checking good boards flagged as defective.
The Photometric 3D Solution
  • Physics 3D Normal Recovery: Inverts multi-angle color ring lighting to compute exact surface normal vectors $[N_x, N_y, N_z]$.
  • Wetting Angle Extraction: Direct measurement of toe and heel wetting angles ($ heta = 15^\circ ext{--}45^\circ$) for strict IPC-A-610 Class 3.
  • Sub-Micron Lead Coplanarity: Measures pin elevation differences ($\Delta Z < 50\,\mu ext{m}$) across QFP/SOIC packages.
  • 0.00% False Call Rate: Deterministic physical metrology combined with deep learning AI.

TECHNICAL EVALUATION
Key Advantages, Trade-offs & Limitations
Advantages & Value
  • Zero False Calls (0.00% FCR): Deterministic physical slope validation eliminates operator fatigue.
  • IPC-A-610 Class 3 Aerospace Conformance: Directly validates mission-critical solder joints.
  • Millisecond Speed (< 25 ms): Matrix inversion and 2D FFT run at 60+ boards/min line rates.
  • Massive ROI: Catches defects early, preventing multimillion-dollar post-production recalls.
Limitations & Mitigations
  • Calibrated Lighting Requirement: Needs 3-tier RGB ring light ($< \$50$ retrofit).
  • Tall Component Shadowing: Tall 15mm caps can cast shadows (mitigated by 4-angle strobing).
  • Shiny SAC300 Inter-Reflections: Solved via Multi-Reflection Suppression (MRS) filter.
  • Compute Load: Optimized via fast NumPy/C++ FFT routines (< 25 ms).
