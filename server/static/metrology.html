IPC-A-610 Class 3 (Aerospace & High-Reliability)

• Maximum Side Overhang: ≤ 25% of component width.
• Maximum Rotational Skew: ≤ 3.0°.
• Mandatory Pin-1 dot index check on all MCU and IC packages.
• Zero tolerance for unseated connector pins or lifted pads.

IPC-A-610 Class 2 (Dedicated Service Commercial)

• Maximum Side Overhang: ≤ 50% of component width.
• Maximum Rotational Skew: ≤ 5.0°.
• Solder fillet minimum height: ≥ 25% of component lead height.
• Overhangs > 50% automatically routed to Rework Station.
